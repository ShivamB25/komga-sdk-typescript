These examples use generated Komga API 1.26.3 operations. Query and path values are flat parameters; `{ client }` is the options argument. Results are non-throwing unless you explicitly add your own throwing boundary.

## Browse latest series

```typescript
import { getSeriesLatest } from 'komga-sdk';

const result = await getSeriesLatest({ page: 0, size: 20 }, { client });

if (result.error) {
  console.error('Could not load latest series', result.error);
} else {
  for (const series of result.data?.content ?? []) {
    console.log(`${series.metadata.title} (added: ${series.created})`);
  }
}
```

### Scope discovery results

The latest, new, and updated endpoints accept `library_id` (an array), `deleted`, `oneshot`, `unpaged`, `page`, and `size`. They are already sorted by the server's discovery rule and do not expose a `sort` parameter. `unpaged: true` is useful for a small export but can be expensive for a large library.

```typescript
const newInLibrary = await getSeriesNew(
  {
    library_id: ['library-123'],
    deleted: false,
    oneshot: false,
    page: 0,
    size: 30,
  },
  { client },
);
if (newInLibrary.error) throw newInLibrary.error;
```

## Get series release years

`getSeriesReleaseYears` returns a paginated `PageString` whose `content` contains release-year values as strings (`string[]`). Read values from `result.data?.content ?? []`:

```typescript
import { getSeriesReleaseYears } from 'komga-sdk';

const result = await getSeriesReleaseYears(undefined, { client });

if (result.error) {
  console.error('Could not load release years', result.error);
} else {
  for (const releaseYear of result.data?.content ?? []) {
    console.log(releaseYear);
  }
}
```

Pass `library_id` or `collection_id` when release years should be scoped. Both scope identifiers are arrays in the v2 operation:

```typescript
const years = await getSeriesReleaseYears(
  { library_id: ['library-123'], collection_id: ['collection-123'] },
  { client },
);
if (years.error) throw years.error;
console.log(years.data?.content ?? []);
```

`getSeriesAlphabeticalGroups` accepts the flat `seriesSearch` body parameter and returns group counts:

```typescript
import { getSeriesAlphabeticalGroups } from 'komga-sdk';

const result = await getSeriesAlphabeticalGroups({ seriesSearch: {} }, { client });

if (result.error) {
  console.error('Could not load alphabetical groups', result.error);
} else {
  for (const group of result.data ?? []) {
    console.log(`${group.group}: ${group.count} series`);
  }
}
```

## Get series from a collection

`getSeriesByCollectionId` uses `id` for the collection identifier and exposes pagination as flat keys:

```typescript
import { getSeriesByCollectionId } from 'komga-sdk';

const result = await getSeriesByCollectionId(
  { id: 'collection-123', page: 0, size: 50 },
  { client },
);

if (result.error) {
  console.error('Could not load collection series', result.error);
} else {
  for (const series of result.data?.content ?? []) {
    console.log(series.metadata.title);
  }
}
```

`getSeriesByCollectionId` also supports flat filters such as `library_id`, `status`, `read_status`, `publisher`, `language`, `genre`, `tag`, `age_rating`, `release_year`, `deleted`, `complete`, and `author`, in addition to `unpaged`, `page`, and `size`. Use those filters instead of fetching every collection series and filtering locally.

## Navigate book siblings

```typescript
import { getBookSiblingNext, getBookSiblingPrevious } from 'komga-sdk';

const nextResult = await getBookSiblingNext({ bookId: 'book-123' }, { client });
if (nextResult.error) {
  console.error('Could not load the next book', nextResult.error);
} else if (nextResult.data) {
  console.log(`Next: ${nextResult.data.metadata.title}`);
} else {
  console.log('This is the last book in the series');
}

const previousResult = await getBookSiblingPrevious({ bookId: 'book-123' }, { client });
if (previousResult.error) {
  console.error('Could not load the previous book', previousResult.error);
} else if (previousResult.data) {
  console.log(`Previous: ${previousResult.data.metadata.title}`);
} else {
  console.log('This is the first book in the series');
}
```

## Common workflows

### Build a "New Releases" dashboard

```typescript
import { getSeriesLatest, getSeriesReleaseYears } from 'komga-sdk';

async function getNewReleasesDashboard() {
  const [latest, releaseYears] = await Promise.all([
    getSeriesLatest({ page: 0, size: 10 }, { client }),
    getSeriesReleaseYears({ unpaged: true }, { client }),
  ]);

  if (latest.error) throw latest.error;
  if (releaseYears.error) throw releaseYears.error;

  return {
    recentlyAdded: latest.data?.content ?? [],
    releaseYears: releaseYears.data?.content ?? [],
  };
}
```

### A-Z navigation

```typescript
import { getSeriesAlphabeticalGroups } from 'komga-sdk';

async function buildAZNavigator() {
  const result = await getSeriesAlphabeticalGroups({ seriesSearch: {} }, { client });
  if (result.error) throw result.error;

  return (result.data ?? []).map((group) => ({
    letter: group.group,
    count: group.count,
  }));
}
```

### Series browser with pagination

```typescript
import { getSeries, getSeriesById } from 'komga-sdk';

class SeriesBrowser {
  private currentPage = 0;
  private readonly pageSize = 20;

  async loadPage(page: number) {
    this.currentPage = page;
    const result = await getSeries(
      {
        page,
        size: this.pageSize,
        sort: ['metadata.title,asc'],
        seriesSearch: {},
      },
      { client },
    );
    if (result.error) throw result.error;
    return result.data;
  }

  async getSeriesDetails(seriesId: string) {
    const result = await getSeriesById({ seriesId }, { client });
    if (result.error) throw result.error;
    return result.data;
  }

  nextPage() {
    return this.loadPage(this.currentPage + 1);
  }

  prevPage() {
    return this.currentPage > 0 ? this.loadPage(this.currentPage - 1) : undefined;
  }
}
```

### Reading order navigator

```typescript
import { getBookSiblingNext, getBookSiblingPrevious } from 'komga-sdk';

class ReadingNavigator {
  constructor(private currentBookId: string) {}

  async next() {
    const result = await getBookSiblingNext({ bookId: this.currentBookId }, { client });
    if (result.error) throw result.error;
    if (!result.data) return null;

    this.currentBookId = result.data.id;
    return result.data;
  }

  async previous() {
    const result = await getBookSiblingPrevious({ bookId: this.currentBookId }, { client });
    if (result.error) throw result.error;
    if (!result.data) return null;

    this.currentBookId = result.data.id;
    return result.data;
  }
}
```

## Error handling

```typescript
import { getSeriesById } from 'komga-sdk';

const result = await getSeriesById({ seriesId: 'series-123' }, { client });

if (result.error) {
  switch (result.response?.status) {
    case 404:
      console.error('Series not found');
      break;
    case 401:
      console.error('Not authenticated');
      break;
    default:
      console.error('Error fetching series', result.error);
  }
}
```
